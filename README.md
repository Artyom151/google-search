# Circle to Search для ПК

Аналог Circle to Search с Android для рабочего стола: по горячей клавише экран
«замирает» с переливающейся рамкой цветов Google. Обведите, зачеркните или
просто кликните по чему угодно — снизу выедет шторка с результатами Google Lens.

## Установка

```sh
pip install -r requirements.txt   # PySide6 (+ cryptography, pynput — по желанию)
./install.sh               # горячая клавиша Meta+S (или: ./install.sh Meta+Alt+S)
```

`install.sh` создаёт ярлык, автозапуск фонового процесса (чтобы окно открывалось
мгновенно) и регистрирует горячую клавишу в KDE. Она заработает после
перезахода в систему, либо назначьте её сразу: Параметры системы → Клавиатура →
Комбинации клавиш → Circle to Search.

Windows / X11: `python circle_search.py --hotkey "<ctrl>+<alt>+s"` (нужен `pip install pynput`).

## Управление

| Действие | Что происходит |
|---|---|
| Обвести / зачеркнуть | поиск по выделенной области |
| Клик | поиск по области вокруг точки |
| Тянуть за уголки / внутри рамки | изменить / сдвинуть выделение, поиск повторится |
| Нарисовать заново | новое выделение |
| Ввести текст в строке «Поиск» | текстовый поиск, а при выделении — поиск по картинке с уточнением |
| Значок Lens в строке поиска | поиск по всему экрану |
| Значок перевода | перевод всего экрана (через Lens с запросом «переведи на русский») |
| Ручка шторки | вверх — развернуть, вниз — закрыть |
| ↗ | открыть результаты в браузере |
| Ctrl+C | скопировать выделение как картинку |
| Esc / ПКМ / ✕ | закрыть |

Оверлей открывается сразу на всех мониторах; выделять можно на любом.
Ссылки на сторонние сайты открываются в обычном браузере.

## Куки и капча

Фото загружается из встроенного браузера с его куками, как в обычном браузере.
Куки хранятся в `~/.local/share/circle-search/`, поэтому войти в Google или
пройти капчу нужно максимум один раз. Можно сразу перенести куки Google
(вход, согласие с cookie, пройденную капчу) из своего браузера:

```sh
python3 circle_search.py --import-cookies chromium   # или chrome, brave
python3 circle_search.py --import-cookies chromium --browser-profile "Profile 1"
```

Для расшифровки нужен `pip install cryptography` и доступ к связке ключей
(KWallet / Secret Service — система может спросить пароль кошелька).

Скриншот на Wayland делается через `spectacle` (KDE) или `grim`.

Иконки в `icons/`: логотипы Google и Google Lens (Wikimedia Commons, public domain) и
Material Symbols от Google (Apache 2.0). Логотипы — товарные знаки Google.

## Язык

Google по умолчанию выбирает язык по IP. Здесь язык передаётся явно: системный,
а если система на `C`/`POSIX` — русский. Сменить (запоминается):

```sh
python3 circle_search.py --lang en
```
